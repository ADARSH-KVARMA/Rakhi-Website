# Memory Images Folder

Place your personal photos in this folder.
By default, the website tries to load the following files:
- memory1.jpg
- memory2.jpg
- memory3.jpg
- memory4.jpg

For best display:
- Use square or portrait aspect ratios.
- Recommended resolution: 800x800px or 800x1000px.
- Keep the file size under 1MB for fast loading on mobile data.

If an image is missing, the website will automatically generate a beautiful fallback placeholder.
