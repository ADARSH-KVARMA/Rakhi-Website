# Background Music Folder

To enable background music, place an MP3 file named:
`background.mp3`
in this directory.

Note:
- Choose a soft, acoustic, instrumental, or nostalgic song.
- Keep the bitrate moderate (e.g. 128kbps) to optimize mobile load time.
- If there is no music file, the website will work perfectly and the music button will simply be hidden or disabled.
